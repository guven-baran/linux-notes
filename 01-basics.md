# Linux Basics — Lesson 1 & 2

## Navigation & Info
| Command | What it does |
|---------|--------------|
| `pwd` | Print the current working directory |
| `ls` | List files and directories |
| `cd <dir>` | Change into a directory |
| `cd ..` | Move one directory up |
| `cd /` | Go to the root directory |
| `whoami` | Show the current user |
| `clear` | Clear the terminal screen |

## Working with Files
| Command | What it does |
|---------|--------------|
| `cat <file>` | Print a file's contents |
| `cp <src> <dst>` | Copy a file or directory |
| `rm <file>` | Remove a file (no undo) |
| `which <cmd>` | Show the full path of a command |

## User Management
| Command | What it does |
|---------|--------------|
| `sudo adduser <name>` | Create a new user account |

## The Linux Filesystem (Directories)
| Path | Purpose |
|------|---------|
| `/` | Root — the top of the filesystem |
| `/bin` | Essential user command binaries |
| `/sbin` | System administration binaries |
| `/usr` | User programs and utilities |
| `/home` | Personal directories for users |
| `/etc` | System configuration files |
| `/dev` | Device files (disks, USB, etc.) |
| `/mnt` | Mount point for temporary filesystems |
| `/media` | Mount point for removable media |
| `/tmp` | Temporary files |
| `/lib` | Shared libraries used by programs |
